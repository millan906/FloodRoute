# scripts/

Utility scripts for data acquisition, environment setup, and other
housekeeping tasks that sit outside the main Python package.

Scripts added here should:
- Be standalone (no implicit dependency on the analysis pipeline state)
- Document their inputs, outputs, and any external tools they require
- Be idempotent where possible

## Stage 0 status

No scripts have been added yet. Acquisition and preprocessing scripts
will be added during Stage 1 (data ingestion).
